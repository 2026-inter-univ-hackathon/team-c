# 実装状況

更新日: 2026-09-23

本書は現在の `main` の実装範囲を示します。将来構想ではなく、コード・マイグレーション・CI設定で確認できる内容を記載しています。

## 実装済み

### 一般ユーザー向け

- トップ、店舗検索、店舗詳細、このブラウザに保存した職場
- 店舗名・エリア検索、業種・最低評価の絞り込み、店舗名・評価・口コミ件数による並べ替え
- 検索条件のURL保持、店舗12件・口コミ10件単位のページング
- 4つの評価軸、投稿者属性、特徴タグ、おすすめ度、生の声を含む口コミ表示
- 投稿者が推測されやすい5件未満での属性の粗粒度表示と年月表示。5件以上では投稿日を上旬・中旬・下旬へ丸める
- 店舗IDだけをブラウザの `localStorage` に保存する「気になる」機能（最大100件）
- ガイドライン、利用規約、プライバシーポリシー、運営者情報、お問い合わせ案内

### 役割切替デモ

- 認証・認可を行わず、求職者向け画面と企業向け画面をボタンで切り替えるデモ導線
- 固定したデモ企業3店舗・架空口コミ4件を対象に、期間・店舗で絞り込み、件数・4評価軸・サマリーを共通集計するダッシュボード。デモ集計は口コミ単純平均で、一般公開側の加重平均とは別。
- 店舗比較表（検索・並べ替え）、4指標の棒グラフ、月別口コミ件数を表示。対象口コミがない店舗は評価を表示しない。
- 改善アクションの進捗と公式回答の下書きをlocalStorageに保存。ダッシュボードとレポートで共有し、再読み込み後も復元。公開送信、店舗追加・編集は未実装。
- 改善レポートは同じ集計データを使用し、人数・単価を入力する費用試算とブラウザ印刷・PDF保存に対応。

この画面切替はログインやアカウントの代替ではありません。企業向け画面はURLを知る利用者が誰でも閲覧できるデモ表示です。

### 口コミ投稿とリアクション

- 全5ステップの投稿フォーム（属性、特徴タグ、4項目評価、生の声、公開プレビューと同意）
- 生の声の30〜300文字検証、禁止語チェック、書き方のヒント、常設の記入例
- サーバー側Zod検証、1ユーザー・1店舗の一意制約、ガイドライン版と同意日時の保存
- 「参考になった」「ありがとう」「役に立った」のリアクション
- 開発環境・明示フラグ・ローカルホストの開発DB名がすべて一致した場合だけ、固定テストユーザーで投稿・リアクションを許可
- 固定テストユーザーの口コミだけを確認・削除する開発用コマンド

投稿とリアクションは認証の代替ではありません。通常環境ではサーバー側で拒否します。

### データ・集計

- PostgreSQL 18 / Drizzleのスキーマ、4本のマイグレーション、開発用seed
- 50店舗、新仕様のダミー口コミ32件、フォーム・質問・評価軸の初期データ
- 口コミ総合点は4評価の算術平均。店舗の評価軸別・総合点は勤続期間と在籍状況を掛け合わせた重み付き平均
- 店舗の評価順は、口コミが少ない店舗を全体平均3.2へ寄せるベイズ補正値を使用。画面には重み付き総合点を表示
- おすすめ度は点数へ含めず、店舗集計値は小数第1位へ丸めて保存
- RouteのServer FunctionからUse Case、Repositoryを経由してDBへアクセス
- 有効な店舗と公開可能な新形式の口コミだけを返し、内部ユーザーID、正確な投稿日、同意日時を公開レスポンスへ含めない

### 品質・運用

- Vitestによる検索入力、公開条件、表示用属性、投稿、リアクション、重複制約、評価計算、お気に入り等の単体テスト
- GitHub ActionsでTest、Lint、Prettier、TypeScript、Build、マイグレーション、seed再実行、スキーマ差分、依存関係監査を実行
- CIに成功した最新の `main` だけをself-hosted runnerから開発デモへ自動デプロイ
- デプロイ前のDBバックアップ、直前リリース保持、起動確認失敗時のコードロールバック

## 検証方針

変更後は `pnpm run test`、`lint`、`format`、`typecheck`、`build` を実行します。DB変更時は空のPostgreSQL 18へマイグレーションとseedを適用し、seedの再実行で重複しないこと、Drizzleスキーマと生成マイグレーションに差分がないことを確認します。

開発DBで投稿機能を確認するときは、投稿、重複投稿、同意拒否、公開環境相当での拒否、リセット対象の限定、公開レスポンスからの内部情報除外を確認します。認証・認可が未実装のため、投稿機能を通常環境へ開放してはいけません。
