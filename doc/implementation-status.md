# 実装状況

2026-09-18時点の作業ツリーに基づきます。要件・設計書は目標仕様を含みます。本書は現在の実装範囲を示し、公開版への反映を意味しません。

## 実装済み

- PostgreSQL 18 / Drizzleのスキーマ、マイグレーション、開発用Seed
- 公開店舗・口コミのRepositoryと入力検証を行うUse Case
- トップ、店舗検索、店舗詳細、気になる職場の4画面
- 店舗名の部分一致検索、都道府県・市区町村の部分一致、業種・最低評価の絞り込み
- 店舗名順・平均評価順・口コミ件数順の並べ替えと、12件単位のページング
- URLでの検索条件保持、0件・読み込み中・取得失敗・店舗不存在の表示
- 店舗詳細の評価軸別メーター、口コミ・勤務情報・質問回答、10件単位の口コミページング
- このブラウザへのお気に入り保存・解除・全解除（店舗IDのみ、最大100件）
- GitHub Actionsによるテスト・型・Lint・整形・Build・DB準備・依存監査の設定（実行結果は別途確認）

機能と手動確認手順は[一般ユーザー向け機能](./public-user-features.md)を参照してください。

## 取得と公開範囲

RouteのServer FunctionからUse Case、Repositoryを経由してDBを読み取ります。検索はDB全体を対象にSQLで集計・絞り込み後にページングします。トップはDB不要ですが、店舗情報の閲覧にはDB接続が必要です。

有効かつ未削除の店舗と、公開済み・未削除・非表示でない・公開日時のある口コミだけを返します。お気に入りのIDを指定してもこの条件を適用します。ユーザーID、メール、認証・セッション情報は公開レスポンスに含めません。

評価は単純平均で、勤続期間による加重平均や参考度は未実装です。全体平均は無効な評価軸も含む既存仕様を維持し、評価軸別サマリーは有効な軸のみを表示します。

## 未実装・残作業

- 認証、セッション、権限制御。現在の公開閲覧にはログイン条件を設けていません。
- 口コミ投稿・編集、プロフィール、組織管理。別ブランチの投稿機能は含めていません。
- お気に入りの端末間同期。ブラウザデータを消去すると保存も失われます。
- 加重平均・参考度、評価軸の無効化時の全体平均との整合性。
- 店舗詳細の既存集計処理の大規模データでの負荷検証。
- Playwrightのプロジェクト依存・CIへの導入。今回のブラウザ検証は作業環境の同梱ランタイムで実施。

## 検証

単体テストは検索入力の境界値、保存データ破損・重複・上限、SQL公開条件、ワイルドカードのエスケープ、SQLパラメータ化、不正入力のDB到達防止を含みます。公開条件の単体テストは生成SQLを検証し、実DBへ非公開行を追加する統合テストではありません。

実DBの開発データで検索・絞り込み・並べ替え・保存／再読み込み／解除・店舗詳細・質問回答をブラウザ確認しました。不正／不存在ID、XSS風検索、壊れた保存データも確認しています。PCおよび390px幅で表示を確認しました。

shadcn/ui、TanStack Form、Playwrightはプロジェクトの依存に追加していません。
