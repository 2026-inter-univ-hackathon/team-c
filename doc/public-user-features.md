# 一般ユーザー向け機能

更新日: 2026-09-23

## 画面

| URL | 機能 |
| --- | --- |
| `/` | サービス説明、店舗名・エリア検索、業種からの検索、使い方 |
| `/stores` | 検索、業種・エリア・最低評価の絞り込み、並べ替え、ページング |
| `/stores/$storeId` | 店舗情報、平均・評価軸別スコア、口コミ、口コミリアクション |
| `/saved` | このブラウザに保存した職場の一覧、保存解除・全解除 |
| `/stores/$storeId/reviews/new` | 開発環境限定の固定テストユーザーによる5ステップ口コミ投稿 |
| `/guidelines` | 口コミ投稿ガイドラインと匿名性の説明 |
| `/terms` | 利用規約 |
| `/privacy` | プライバシーポリシー |
| `/operator` | 運営者情報 |
| `/contact` | お問い合わせ・削除依頼の案内 |

店舗検索と口コミ閲覧は公開の読み取り処理です。投稿と口コミリアクションは、認証導入まで明示的に許可した開発環境の固定テストユーザーに限定し、通常環境ではサーバー側で拒否します。

## 検索仕様

- 店舗名は部分一致、エリアは都道府県または市区町村の部分一致です。複数条件はANDです。
- 業種は有効なカテゴリのみ、最低評価は0〜5です。
- 並び順は店舗名・平均評価・口コミ件数です。評価のない職場は評価順で最後にし、同順位は名前・IDで順序を固定します。
- 店舗は12件、口コミは10件単位で表示し、範囲外のページは最後のページに補正します。
- 検索条件はURLに保持し、再読み込みや戻る操作で再現できます。
- SQLの `%` と `_` は検索文字としてエスケープし、ユーザー入力をSQLへ連結しません。
- 非公開・削除済み店舗と口コミは返しません。

## 口コミ表示と評価

- 評価軸は「職場の雰囲気」「教育・フォロー体制」「業務のゆとり」「シフトの融通度」です。
- 個々の口コミ総合点は4評価の算術平均です。
- 店舗の評価軸別・総合点は、勤続期間（3ヶ月未満0.8、3ヶ月以上〜1年未満1.0、1年以上1.1）と在籍状況（勤務中1.2、退職1年未満1.0、退職1年以上0.7）を掛け合わせて重み付けします。
- 店舗の評価順は、口コミが少ない店舗を全体平均3.2へ寄せるベイズ補正値を使用します。画面へ表示する評価と最低評価の絞り込みには、重み付き総合点を使用します。
- おすすめ度は点数へ含めず、旧プロトタイプの「参考度 高／中／低」は表示しません。
- 公開口コミが5件未満の店舗では投稿者属性を大まかにし、勤務期間を隠し、投稿日を年月までに丸めます。5件以上では投稿時点の在籍状況、立場、勤務期間を表示し、投稿日を日本時間の上旬・中旬・下旬へ丸めます。
- 内部ユーザーID、Email、正確な日時、ガイドライン同意日時は公開レスポンスへ含めません。

## 「気になる」保存

- 保存対象は店舗IDだけで、ブラウザの `localStorage` に最大100件保存します。
- アカウントやDBには保存せず、別ブラウザ・別端末とは同期しません。
- URLから保存IDを受け付けません。不正な形式のIDを除外し、重複を取り除きます。
- 非公開・削除済み店舗は保存一覧へ表示しません。表示できない保存項目も「保存をすべて解除」で消せます。
- 「気になる」は利用者自身の候補保存であり、AIによる推薦や採否判断ではありません。

## 投稿フォーム

1. 在籍状況、立場、勤務期間
2. 職場の雰囲気、スタッフ層、店長の関与度
3. 4項目の評価とおすすめ度
4. 30〜300文字の生の声
5. 公開プレビュー、ガイドライン確認、同意、送信

Step 4では設問、補足説明、書き方のヒントチップ、プレースホルダー、常設の記入例を表示します。戻る操作で入力を保持し、各ステップと最終送信時に検証します。本文はReactのテキストとして描画し、HTMLとして解釈しません。

## デザイン

`#FF6A2B` を主要操作とアクセント、`#75402A` を見出し・情報の強調、`#FFCAB3` を補助背景に使用します。白と暖色の背景を組み合わせ、PCでは条件サイドバー、スマートフォンでは縦並びにします。faviconとヘッダーには同じブランドマークを使用します。

店舗写真は業種イメージであることを画面上に示します。画像はリポジトリ内の `img/` と `public/` から配信し、画面表示時に外部画像サービスへ接続しません。

## 主な実装ファイル

- `src/routes/`: 画面、URL状態、loader、Server Functions
- `src/components/site-shell.tsx`: 共通ヘッダー・フッター
- `src/features/stores/`: 検索フォーム、店舗表示、口コミカード、端末内保存
- `src/schemas/`: 検索、投稿、リアクションのZod検証
- `src/server/use-cases/`: 検索、公開店舗取得、口コミ投稿、リアクション
- `src/server/repositories/`: DB検索、公開範囲の限定、保存・集計
- `src/styles.css`: 配色、レイアウト、レスポンシブ表示

## 手動確認

1. トップの検索から店舗一覧へ進み、店舗名・エリア・業種・最低評価を変更する。
2. 条件付きURLを再読み込みし、条件と結果が維持されることを確認する。
3. 並べ替え、結果0件、ページ移動、不正・存在しない店舗IDを確認する。
4. 店舗を保存し、再読み込み後も残ること、保存解除・全解除・保存拒否時のメッセージを確認する。
5. 店舗詳細で少数口コミと5件以上の属性表示、日付の曖昧化、口コミページングを確認する。
6. 開発投稿を有効にした環境で全5ステップ、戻る操作、境界値、禁止語、プレビュー、同意拒否、重複投稿を確認する。
7. スマートフォン幅、キーボード操作、フォーカス、長い文言の折り返しを確認する。

投稿・リアクションAPIとDBスキーマを含むため、公開条件、環境制限、入力検証、エラー情報の非開示、他ユーザーのデータ混入を重点的にレビューしてください。
