# バイトのホンネ

働く側の声で「このバイト、自分に合うか」を判断するレビューアプリ。

## 何を作ったか

バイトを探す学生は、求人票の時給とシフト条件しか比べられない。実際に効くのは
「同世代がいるか」「シフトの希望が通るか」「日払いか」なのに、それは働いた人しか知らない。

このアプリは、その4つを**働いた人のレビュー**として集める。特徴は、レビューに
**投稿者の属性（勤続期間・年齢層・立場）が必ず付く**こと。勤続3日の人の★5と2年働いた人の★3を
同じ重さで平均しても意味がないので、**勤続期間で重みづけした加重平均**を点数として出し、
1件ごとに「参考度 高／中／低」を表示する。「☆4.2（12件）」が、誰の声なのかまで見える。

## 使った技術

- HTML / CSS / JavaScript（素のまま）
- データの保存: localStorage（キー `app-data` 1つ）
- 画像: `img/` に同梱（サムネイルは Unsplash の写真、アイコン等は自前 SVG）。外部サイトからは読み込まない

（**9/4 時点の構成です。** 開発期間で変えたら、ここも書き換えてください）

画面は `index.html` の1枚だけ。動線も1本：

```
① 重視することを選ぶ（最大3つ）
      ↓
② バイト先が、その重視項目で並び替わる
      ↓
③ カードを開く → 項目別スコア・働き方の事実・属性つきレビュー
      ↓
④ 人が「気になる／見送る」を押す   ← AI に任せない部分
      ↑
⑤ レビューを投稿すると ② に反映される
```

## 動かし方

`index.html` をブラウザで開いてください。ビルドやインストールは不要です。

公開版（GitHub Pages）: https://2026-inter-univ-hackathon.github.io/team-c/

初回は内蔵のデモデータ（4バイト先・13レビュー）が表示されます。画面下の
「保存内容をリセットしてデモデータに戻す」でいつでも初期状態に戻せます。
データは開いた人のブラウザにだけ保存されるモックなので、投稿は他の人には見えません。

## AI に任せなかった部分

**「気になる／見送る」を押すところ。** アプリは点数を出して並び替えるが、採用も却下もしない。
そもそも「何を重視するか」を選ぶのも人（①）。

バイトを選ぶ基準は、金か・人間関係か・シフトかで人によって違い、平均点では決まらない。
AI に足りないのは **「自分にとって何が大事か」の重みづけ**で、それは①で人が選び、④で人が確定する。
