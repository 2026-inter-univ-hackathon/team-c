# バイトのホンネ

働く側の声で「このバイト、自分に合うか」を判断するレビューアプリ。

## 何を作ったか

バイトを探す学生は、求人票の時給とシフト条件しか比べられない。実際に効くのは
「同世代がいるか」「シフトの希望が通るか」「日払いか」なのに、それは働いた人しか知らない。

旧プロトタイプでは、その4つを**働いた人のレビュー**として集める。特徴は、レビューに
**投稿者の属性（勤続期間・年齢層・立場）が必ず付く**こと。勤続3日の人の★5と2年働いた人の★3を
同じ重さで平均しても意味がないので、**勤続期間で重みづけした加重平均**を点数として出し、
1件ごとに「参考度 高／中／低」を表示する。「☆4.2（12件）」が、誰の声なのかまで見える。

## 現在の実装状況

2026-09-21時点の作業ツリーでは、一般ユーザー向けの検索・閲覧・端末内のお気に入りと、開発環境限定の5ステップ口コミ投稿を実装しています。公開版への反映を意味するものではありません。

- トップページ、店舗検索、店舗詳細、気になる職場の4画面
- 店舗名・エリア検索、業種・最低評価の絞り込み、評価・口コミ件数による並べ替え
- 検索条件のURL保持、店舗12件・口コミ10件単位のページング
- 平均評価・評価軸別メーター・勤務情報・質問回答
- ブラウザ内での保存・解除・全解除（店舗IDのみ、最大100件）

認証・セッション・認可、口コミ編集、プロフィール、組織管理は未実装です。投稿は明示的に有効化した開発環境だけで固定テストユーザーとして行い、公開環境では受け付けません。総合点は4項目の単純平均で、旧プロトタイプの加重平均・参考度は未移植です。

[一般ユーザー向け機能](doc/public-user-features.md)に操作・検索仕様、[実装状況](doc/implementation-status.md)に実装範囲と残作業を記載しています。

2026-09-17時点でもTanStack Start版への移行を進めています。以下は旧プロトタイプの動線であり、新実装の対応範囲は上記「現在の実装状況」を参照してください。
画面は `src/routes/index.tsx` から始まるTanStack Startアプリです。旧プロトタイプは `legacy/index.html` に残しています。旧プロトタイプの動線は次の通りです。

```
① 重視することを選ぶ（最大3つ）
      ↓
② バイト先が、その重視項目で並び替わる
      ↓
③ カードを開く → 項目別スコア・働き方の事実・属性つきレビュー
      ↓
④ 人が「気になる／見送る」を押す   ← AI に任せない部分
      ↑
⑤ レビューを投稿すると ② に反映される
```

## 動かし方

Node.jsと、`package.json` の `packageManager` に指定されたpnpmを用意してください。

```bash
pnpm install
pnpm dev
```

開発サーバーは http://localhost:3000 で起動します。トップページにはDB接続は不要ですが、店舗一覧・詳細にはDBが必要です。

店舗画面を確認する場合は、開発用PostgreSQL 18のDBを用意し、プロジェクト直下の `.env` に `DATABASE_URL` を設定します。接続情報はコミットせず、チャットやログにも貼り付けないでください。DB環境の自動セットアップは含まれていません。

```bash
pnpm run db:check-dev
pnpm dev
```

Seedは明示的に設定した開発用DBにのみ投入してください。`DEV_DATABASE_NAME` と `ENABLE_DEV_REVIEW_POSTING=true` が必要です。旧ダミー口コミからの移行を含む詳しい手順は[新しい口コミ投稿フローの開発手順](doc/review-flow-development.md)を参照してください。

## AI に任せなかった部分

**「気になる／見送る」を押すところ。** アプリは点数を出して並び替えるが、採用も却下もしない。
そもそも「何を重視するか」を選ぶのも人（①）。

バイトを選ぶ基準は、金か・人間関係か・シフトかで人によって違い、平均点では決まらない。
AI に足りないのは **「自分にとって何が大事か」の重みづけ**で、それは①で人が選び、④で人が確定する。
